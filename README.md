# Set 19 Comps

A small static site with TFT Set 19 (Prismatic Tour) team comps for friends:

- **Early game (lv 4-5)** – cheap openers and the board each one grows into
- **Lv 8-9 boards** – level 7 / 8 / 9 versions of each comp
- **Reroll comps** – 3-star carries, the level to roll at, and how to scale out
- **Cheat sheet** – searchable list of anti-heal, shred, CC, econ units, unlocks, emblems and trait breakpoints

Set 19 is on PBE, so everything here is theory-crafted and may change. Open `index.html` or host the folder on GitHub Pages (no build step).
Unit data from MetaTFT's PBE data file; portraits and team-builder links from tactics.tools. Not endorsed by Riot Games.
