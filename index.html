Method & caveats

  • Data. Set 19 units, costs, traits and breakpoints: MetaTFT PBE lookup file (TFTSet19_latest_en_us.json). Beach Pop is listed with breakpoint 0 in that file; MetaTFT's set page shows 3 / 5 / 7, which is used here.
  • K/DA counts star levels. The script assumes 1-3 cost units are 2-star on level 8-9 boards and only 1-costs are 2-star on level 4-5 boards. At 1-star, K/DA numbers drop.
  • Unique traits. 1-unit traits (Tango, Beat Master, 8-Bit, Synthwave, Composer...) are shown as active and counted in "active traits", but listed separately. The PBE tooltip says Jazz and the Smeech unlock count only non-unique traits, so cards also show the non-unique count. Heartsteel (breakpoint 1) and R&B (breakpoint 1) are non-unique traits that one unit can turn on.
  • Ignored. Collab (members change every game), Sona (level-10 unlock) and the 7-cost chase units except where a card says so.
  • Unlockables are marked with ◆. They need a mid-game condition, so treat them as upside, not as the plan.
  • Search. A beam search scored boards by active traits (first breakpoint = 1 point, each extra tier +0.35, unique +0.4), minus wasted units and dead units, with hard limits on tanks (2+ early, 3+ late), backline (1+ early, 2+ late), cost curve and unlockables; the shortlist was then curated by hand around real carries.
  • Positions in team-builder links are a starting layout (front row = row 4), not optimised positioning.
  • Not verified in game. Nothing here has been played on PBE by this page's author; numbers for Set 18 are real ladder stats, everything for Set 19 is a hypothesis.
